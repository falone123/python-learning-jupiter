# Python Learning Notebooks

ကျွန်တော့် Python လေ့လာရေး မှတ်စုများ။
အောက်က badge ကိုနှိပ်ရင် browser ထဲမှာ တိုက်ရိုက် run လို့ရပါတယ်။

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/ppz/python-learning/HEAD)

## သင်ခန်းစာများ
1. `01-basics.ipynb` — print, variables, data types
2. `02-strings.ipynb` — string များ
3. `03-lists-dicts.ipynb` — list, tuple, dict, set
4. `04-loops.ipynb` — for, while
5. `05-functions.ipynb` — function, scope

> မှတ်ချက်: Binder session က ယာယီဖြစ်ပါတယ်။ လုပ်ပြီးသား notebook ကို
> download လုပ်ပြီး ဒီ repo ထဲ ပြန်တင်ထားပါ။
